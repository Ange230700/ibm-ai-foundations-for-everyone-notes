## Design findings

- Preserve actual choice while keeping scope manageable: handover or checklist from one packet.
- Supply all facts and permissions so participants never have to invent organizational rules.
- Include an offline path and distinguish simulated responses from actual tool runs.
- Keep independent verification after iteration, even if the new answer appears better.
- Include checking and correction in value measurement, and allow an unestablished benefit.
- Keep approval pending rather than invent an approver's decision to create a finished-looking result.
- Use concurrent explanations to fit the 60-minute envelope for more than one learner.
- Preserve a separate transfer case without importing cooperative authority into it.

## Explicit proposed decisions

The draft adopts 60 minutes and 25 slides, individual or paired practice, formative feedback and
localized reference extracts with a working template. These are reversible implementation choices
for instructor review. They do not finalize the program name or create a formal certification.
