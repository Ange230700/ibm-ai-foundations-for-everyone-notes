# Building AI Powered Chatbots Without Programming

## Course overview

This beginner-level IBM course on Coursera covers the design, construction, refinement, and deployment of AI-powered chatbots without requiring programming. The supplied course material uses IBM watsonx Assistant and a fictitious flower shop as the running example.

The course progresses from chatbot fundamentals and action workflows through decision-tree design, action and session variables, conversational improvements, recommendation logic, deployment environments, WordPress deployment, and a final exam.

## Learning outcomes

- Explain what chatbots and virtual assistants are and describe their principal business benefits.
- Compare decision-tree chatbots with generative AI chatbots in terms of control, flexibility, predictability, and use cases.
- Build action workflows in IBM watsonx Assistant without programming.
- Use action variables and session variables to manage task-specific data and conversational context.
- Improve chatbot interactions with greetings, thank-yous, farewells, response variations, follow-up questions, expressions, and structured recommendation logic.
- Publish a chatbot from Draft to Live and deploy it through channels such as Web chat and WordPress.
- Test complete chatbot conversations and reason about deployment, scalability, extensions, and multi-channel delivery.
