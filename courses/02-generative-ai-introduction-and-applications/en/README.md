## Learning outcomes

- Distinguish generation from classification and prediction.
- Recognize text, image, audio, video, code, synthetic-data and virtual-world capabilities.
- Connect an industry need to an output and a review method.
- Apply concepts to text, image and simple code exercises while retaining source uncertainties.
