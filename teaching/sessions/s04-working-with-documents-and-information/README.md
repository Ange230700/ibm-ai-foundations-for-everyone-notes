# S04 — Travailler avec des documents et des informations

Ce dossier contient les sources pédagogiques bilingues de la séance professionnelle S04.

La séance est indépendante de la numérotation des cours canoniques. Sa provenance initiale repose
sur trois modules effectivement utilisés :

- Course 02 / Module 02 — Applications and Tools of Generative AI ;
- Course 03 / Module 02 — Prompt Engineering: Techniques and Approaches ;
- Course 01 / Module 04 — Issues, Concerns, and Ethical Considerations.

Le cours canonique 04 sur les chatbots n’est pas utilisé par défaut.

Le [contrat pédagogique S04](../../../docs/teaching/s04-documents-information-60-min-content-contract.md)
fixe **25 diapositives** et **60 minutes** dans chaque langue. L’[audit de fusion](../../../docs/teaching/s04-professional-fusion-audit.md) fixe les limites de
provenance, de responsabilité humaine et de contenu.

## Sources pédagogiques

- Français : `fr/session.md`
- Anglais : `en/session.md`

Les deux sources utilisent les mêmes identifiants, durées, types de contenu projeté, faits fictifs
et limites de décision. Le paquet de sources Soubré est volontairement borné : SB-104 comporte deux
poids contradictoires, tandis que SB-105 a un poids manquant.

## Statut de production

Ces fichiers constituent un **brouillon pédagogique bilingue**. Ils doivent être validés par le
parseur de séance, relus, enregistrés dans `manifest.json`, construits en PDF/PPTX, contrôlés
visuellement et répétés avant clôture de S04.

L’attribution à IBM/Coursera et la déclaration de génération avec l’IA doivent rester visibles dans
les supports finaux.
